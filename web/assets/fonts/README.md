# 字帖预览字体

以下字体由各项目的原版 TTF 转换成 WOFF2，供本地网页预览和打印使用。原始授权文本保留在本目录；练字帖的其他代码许可与字体许可分别适用。

| 页面选项 | 字体 | 来源 | 许可 |
| --- | --- | --- | --- |
| 楷体 | LXGW WenKai | https://github.com/lxgw/LxgwWenKai | OFL-LXGWWenKai.txt |
| 行书 | Zhi Mang Xing | https://github.com/google/fonts/tree/main/ofl/zhimangxing | OFL-ZhiMangXing.txt |
| 宋体、宋体加粗 | ZCOOL XiaoWei | https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei | OFL-ZCOOLXiaoWei.txt |
| 书法体 | Long Cang | https://github.com/google/fonts/tree/main/ofl/longcang | OFL-LongCang.txt |
| 圆体 | Huninn | https://github.com/google/fonts/tree/main/ofl/huninn | OFL-Huninn.txt |
| 英文手写 | Caveat | https://github.com/google/fonts/tree/main/ofl/caveat | OFL-Caveat.txt |

黑体使用系统无衬线字体。原有“隶书”选项的本地字体实际是龙藏书法字形，因此页面改称“书法体”；旧配置中的 lishu 值仍可读取。
